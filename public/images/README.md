# That's Okay. image files

To replace an image, simply replace the file with the same filename. No code changes are required.

- `disha-hero.jpg` — portrait shown on the About Disha hero
- `disha-about.jpg` — portrait shown on the About Disha content section
- `home-disha.jpg` — portrait shown on the homepage
- `resource-articles.jpg` — image for Articles
- `resource-events.jpg` — image for Events & Workshops

Recommended: JPG or WebP, landscape/portrait as appropriate. Keep filenames exactly the same.
